# Rutas Seguras Kids

Demo académica para organizar rutas escolares y asignar estudiantes a cada ruta.

## Funciones

- Crear, editar y eliminar rutas y registros de demostración.
- Buscar por nombre o ciudad y filtrar estudiantes por ruta.
- Guardar cambios en `localStorage` del navegador.
- Consultar temperatura actual mediante Open-Meteo, sin clave de API.

Todos los registros incluidos son ficticios. La aplicación no tiene backend, autenticación ni controles suficientes para almacenar información real de menores; no introduzcas datos personales.

## Tecnologías

`HTML` · `CSS` · `JavaScript` · Web Components

## Vista local

Abre `index.html` en un navegador con conexión a Internet para consultar el clima. Los cambios quedan guardados únicamente en el navegador actual.
